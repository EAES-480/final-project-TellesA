# data

Place data file(s) in this folder.

Then, include codebooks (variables, and their descriptions) for your data file(s)
using the following format.

## Survey Results Data

- `PbMeasurement_ppm`: Lead concentrations of surface soil in parts per million
- `SamplingSite`: Site or transect where data was collected
- `Pb2`: Survey results variable
- `SiteGroup`: categorization of the sites
